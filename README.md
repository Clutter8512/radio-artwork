# Radio Artwork

A collection of custom artwork for internet radio stations.

This repository exists to provide high-quality square artwork that can be used with applications such as Symfonium, VLC, Kodi, and other media players that support custom station images.

## Goals

- Create attractive, consistent artwork.
- Preserve artwork at high resolution.
- Provide stable URLs through GitHub.
- Cover game music, electronic, jazz, classical, and other internet radio stations.

| Station | Description |

## Image Format

- PNG
- Square (1024×1024 recommended)
- Optimized for dark and light themes
